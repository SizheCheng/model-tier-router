# Provenance

The public release candidate contains the newly structured advisory core,
governed compatibility contracts, documentation, schemas, examples, and tests
listed in `PUBLIC_MANIFEST.json`.

The managed Codex development-data integration was reconstructed through an
explicit cleanroom allowlist containing only generic source, schema,
documentation, and tests. Runtime ledgers, product-lane contracts, machine
installation evidence, local absolute paths, and private execution packets are
not part of this public repository.

An earlier byte-identical classifier implementation, system-specific adapters,
private closeout evidence, local paths, and generated bytecode are excluded.
Required compatibility behavior was reimplemented around the published JSON
contracts and regression tests rather than exporting that earlier file.

The repository owner selected Apache-2.0 for this release candidate and
identified Sizhe Cheng as the 2026 copyright holder. This record describes the
engineering boundary; it does not claim legal certainty about excluded
historical material or override third-party rights.

No retained dependency creates a concrete attribution requirement, so this
candidate does not include a NOTICE file.
